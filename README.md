# campaign-report

## Запуск

```
npm install
npm run build
node dist/cli.js --spend <file> --revenue <file> --format md|csv [--out <file>]
```

`--spend` і `--revenue` — CSV з колонками `campaign` і `spend`/`revenue` відповідно (регістр і пробіли в заголовку не важливі, зайві колонки ігноруються). Розділювач `,` або `;` визначається автоматично, дробова частина через `.` або `,`.

Без `--out` звіт іде в stdout, а звіт помилок — у stderr. З `--out` звіт пишеться у вказаний файл, а проблеми — у `<out>.errors.csv` (файл перезаписується щоразу, тож після чистого запуску в ньому лишається тільки заголовок); у stderr тоді йде короткий підсумок.

Код виходу `0`, якщо звіт побудовано, навіть коли частину рядків пропущено. Код `1` — якщо аргументи неправильні, файл не читається або у файлі немає потрібної колонки; у цьому разі звіт не створюється.

Приклад:

```
$ node dist/cli.js --spend fixtures/basic/spend.csv --revenue fixtures/basic/revenue.csv --format md
| campaign | spend | revenue | ROI |
| --- | ---: | ---: | ---: |
| black-friday | 3400.00 | 2890.75 | -14.98% |
| brand-awareness | 750.25 | 1500.00 | 99.93% |
| winter-sale | 1200.50 | 2400.00 | 99.92% |
| Total | 5350.75 | 6790.75 | 26.91% |
```

Тести: `npm test` (перед запуском сам збирає `dist/`, бо e2e гонить справжній CLI). Перевірка типів: `npx tsc --noEmit`.

## Відомі обмеження

Усе нижче — відома й свідома поведінка, а не плани. Якщо щось із цього заважає, це окрема задача.

**Дані, які зникають або зливаються**

- Кампанія, яка **справді** називається `Total`, `Разом`, `всього` або `итого`, пропускається як рядок підсумку з вивантаження. У звіті помилок про це є попередження, але гроші в звіт не потрапляють.
- Назви зливаються без урахування регістру, типу апострофа (`'` `ʼ` `’`), нерозривного пробілу та невидимих символів. У звіт іде перше написання, очищене від невидимих символів; решта написань — у попередженні `злито:`, де невидимі символи показані кодами (`Black<U+00A0>Friday`).
- Рядок, у якому бракує лише останнього необов'язкового поля (заголовок `campaign,spend,note`, рядок `Promo,100`), відкидається цілком як «замало полів». Помилка видна, але сума зі звіту зникає.
- Суми довші за 15 цифр відкидаються: далі Number() почав би тихо губити молодші цифри.
- Від'ємні та нульові витрати дають ROI `-` (погоджене правило). Повернення коштів зменшують рядок `Total` без окремого попередження.

**Шум у звіті помилок**

- Порожні рядки з Excel (`,,` або `;;`) дають помилку «порожня назва кампанії» на кожен такий рядок і роздувають `Пропущено рядків`.
- Для запису в лапках, що займає кілька рядків, у звіті вказано **останній** рядок запису, а не перший.

**Читання файлу**

- Розділювач визначається за першим рядком. Якщо коми і крапки з комою там однаково часто (`campaign;spend, UAH`), обирається кома і файл не читається. Обхід: додати першим рядком `sep=;`. Але це лікує тільки розділювач — колонка в цьому прикладі називається `spend, UAH`, а шукається рівно `spend`, тому заголовок усе одно доведеться виправити.
- Будь-яка інша преамбула над таблицею (порожній рядок, заголовок звіту, `sep=` з іншим символом) з'їдає рядок заголовка — буде фатальна помилка «немає колонки campaign».
- Файл мусить бути в UTF-8. Windows-1251 (типове «Зберегти як CSV» в Excel з українською локаллю) відхиляється з підказкою, а не читається в ромбики.

**Вивід**

- CSV завжди з розділювачем-комою і крапкою в числах. Excel з українською локаллю може відкрити такий файл одним стовпцем, а суми на зразок `12.05` прочитати як дати. Обхід: імпорт через «Дані → Отримати дані → З текстового файлу».
- Назви, що починаються з `=`, `+`, `@` або `-`, у CSV префіксуються апострофом, щоб Excel не виконав їх як формулу. У клітинці буде видно цей апостроф.
- Перенос рядка в назві кампанії ламає markdown-таблицю: екранується тільки `|`.

**Код виходу і режим `--out`**

- Код виходу `0`, навіть коли частину рядків пропущено. Скрипт-обгортка цього не побачить — перевіряйте stderr або `<out>.errors.csv`.
- Якщо проблеми лише попередження, у stderr усе одно йде `Пропущено рядків: 0`.
- Звіт пишеться раніше за `<out>.errors.csv`. Якщо запис файлу помилок не вдасться, звіт уже на диску — лишиться напівстан.
- Повторений прапорець мовчки бере останнє значення: `--spend a --spend b` прочитає `b`.
- ROI рахується цілими числами з мінорних одиниць. Якщо різниця доходу і витрат перевищує приблизно 9 млрд одиниць валюти, чисельник (× 10000) виходить за межі точних цілих.
